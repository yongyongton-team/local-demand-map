# 생기면 갈게요 (가칭)

2026 용용톤 상권 트랙 출품작이에요.

동네에 **없는 가게**와 주민이 **원하는 가게**가 보이는 지도예요. 주민 요청이 모이면 그 데이터로 사장님은 갈 동네를, 예비 창업자는 가게를 열 동네를 찾아요.

## 누가 무엇을 하나요

| 누가 | 무엇을 |
|---|---|
| 주민 | 동네 지도에서 없는 가게를 보고, 생겼으면 하는 가게를 문장으로 요청해요 |
| 사장님 | 내 업종을 원하는 동네와 조건(시간대, 원하는 점)을 보고, 선주문 수령을 제안해요 |
| 예비 창업자 | 요청은 많고 가게는 없는 동네 순위와, 공공데이터로 만든 근거 리포트를 봐요 |

AI는 두 곳에만 써요.

- 주민이 쓴 문장을 업종과 조건으로 정리해요.
- 서버가 계산한 숫자로 요약 문장을 써요. 문장에 없는 숫자가 나오면 버리고 기본 문장을 써요.

## 폴더

| 폴더 | 내용 |
|---|---|
| `frontend/` | 화면(주민·사장님·창업자)과 지도 |
| `backend/` | API 서버 |
| `ai/` | AI 요청 정리·요약 문장, 빈 업종 계산 |
| `data/` | 공공데이터 받는 법과 출처 |
| `docs/` | 기획·설계 문서 링크 |

## 쓰는 데이터

- 경기도 용인시 대규모 점포 현황 (용인시가 직접 낸 데이터)
- 소상공인시장진흥공단 상가(상권)정보
- 통계청 SGIS 행정동 경계

자세한 출처와 받는 법은 [`data/README.md`](data/README.md)에 있어요.

## 실행 방법

기술 스택이 정해지면 각 폴더 README에 적어요.

## 환경변수

`.env.example`을 복사해 `.env`를 만들고 값을 채워요.

```bash
cp .env.example .env
```

`.env`와 키 파일은 절대 커밋하지 않아요. `.gitignore`가 막아 두었어요.

## 협업 규칙

- `main`에 바로 올리지 않고, 브랜치를 만들어 PR로 합쳐요.
- 브랜치 이름은 `파트/할일`로 써요. 예: `fe/map-screen`, `be/requests-api`, `ai/request-parse`
- PR은 한 명 이상이 확인한 뒤 합쳐요.
- `main`은 언제나 실행되는 상태로 둬요. 마지막 날 한꺼번에 합치지 않아요.
- 11/14부터는 새 기능을 넣지 않고 버그만 고쳐요.
